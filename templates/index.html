OpenCV AI Engine

Multimodal Biometrics

Combines OpenCV minutiae extraction using ORB feature detection with spatial Local Binary Pattern (LBP) facial embeddings. Both checks must pass simultaneously for access.

  • Adaptive CLAHE & Gabor Filtering
  • Protected Biometric Hashes
  • Zero Raw Biometrics Stored on Chain

ECDSA Digital Signatures

Voters sign vote transactions using SECP256K1 elliptic curve private keys. Non-repudiation is guaranteed while preserving ballot privacy via pseudonymous voter token hashes.

  • SECP256K1 Curve (Ethereum-grade)
  • Decoupled Ballot Identity
  • Strict Single-Vote Guarantee

Tamper-Evident Ledger

Every cast vote forms a cryptographic block linked via previous SHA-256 hashes and Proof-of-Work mining. Any retroactive block modification breaks chain integrity immediately.

  • Deterministic Canonical Hashes
  • Real-Time Tamper Detection UI
  • Extensible for Web3 & Ethereum

Complete System Workflow Architecture

The secure step-by-step pipeline executed from voter enrollment to immutable blockchain recording:

1-4 Registration & Enrollment
Voter enters credentials. OpenCV captures & stores protected fingerprint minutiae and face embeddings.
5-6 Multimodal Verification
Dual biometric check. Both fingerprint and face must match enrolled templates. Rejects if either fails.
7-8 Eligibility & Anti-Duplicate
Verifies age ≥ 18 and checks has_voted flag. Rejects duplicate voting attempts strictly.
9-10 Ballot Cast & SHA-256
Voter selects candidate. Payload is hashed using SHA-256 and signed with voter's ECDSA private key.
11-13 Blockchain Sealing
Mines new block linked to previous hash. Verifies PoW. Sets has_voted = 1 in SQLite.
14-17 Closure & Official Tally
Admin closes election. On-chain votes are tallied independently and cross-audited against database.
